## About this project

A responsive, standalone landing page and registration form built for KDAG's
Beginner's Python & Data Analytics Bootcamp.

This submission includes:

- index.html — the bootcamp landing page (hero, curriculum, about, and a call to register).
- register.html — the registration form (Name, Roll Number, Email, Department), with client-side JavaScript validation and a stylized success state.
- style.css — shared styling: a dark, editorial theme in KDAG's crimson/gold palette with an animated data-network background.
- script.js — the ambient network-canvas animation and all form validation logic.

## Validation implemented

- All fields are required; empty submissions are flagged inline.
- Roll number must be exactly 9 characters.
- Email is checked against a standard email pattern.
- On a fully valid submission, the form is replaced with a "Registered successfully!" confirmation showing the entered details.
